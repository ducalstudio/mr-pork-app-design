# image-placeholder

Status: **Draft / Provisional** (not an approved Design System component).

Neutral hatch block standing in for CMS images, illustrations and icons. No asset is invented or derived from the Reference. Replace with real assets when supplied.

- Variants: default (fills its container), `--square` (1:1).
- Decorative by default: give it `aria-hidden="true"`. If it stands for real content, give the parent a text alternative.

## Variant circle (Batch 2)

`image-placeholder--circle`: avatar and notification thumbnail stand-in.
