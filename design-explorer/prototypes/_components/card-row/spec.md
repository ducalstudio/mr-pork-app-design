# card-row

Status: **Draft / Provisional** (not an approved Design System component).

A horizontally scrolling row of cards; the last card peeks in so the row reads as scrollable.

- **Content type is unknown.** In Home — Member the cards are neutral (glyph + plain label + image slot). No outlet, product or category is implied. Content type, source and destination are `To Verify`.
- The row is keyboard focusable; arrow keys scroll it.
- Card width is constant across tiers.
